# HowStuffWorks — Claudeway 🚀

A kid-friendly explainer app. Ask any *"How does X work?"* question and get a 4-slide illustrated lesson with voiceover — all generated by **Claude** in a single API call.

## Why this version

Your original app used:
- Paid OpenAI image generation (expensive, unpredictable results)
- Server-side audio (storage, latency)
- Multiple API calls per lesson

This rebuild uses:
- ✅ **One** Claude API call generates slide text + SVG illustrations + narration
- ✅ **Zero** image API costs — Claude draws labeled SVG shapes
- ✅ **Zero** audio infrastructure — browser Web Speech API does voiceover
- ✅ Auto-play mode with synced voice-to-slide advance

## Stack

| Layer | Choice |
|---|---|
| Backend | Flask (Python) |
| AI | Claude Sonnet 4.6 via Anthropic API |
| Illustrations | Claude-generated SVG |
| Voiceover | Browser `SpeechSynthesis` API |
| Frontend | Vanilla JS + Jinja2 + CSS |

## Quick start

```bash
# 1. Clone / cd into this folder

# 2. Install
pip install -r requirements.txt

# 3. Configure
cp .env.example .env
# Edit .env and paste your key from https://console.anthropic.com

# 4. Run
python app.py
```

Visit http://localhost:5000

## How it works

1. User types a question like *"How do rockets fly?"*
2. Flask sends it to Claude with a carefully crafted system prompt
3. Claude returns JSON containing 4 slides — each with title, explanation, fun fact, narration text, and a full inline SVG illustration
4. Flask renders the slides in a player UI
5. The browser's built-in speech synthesis reads each slide aloud
6. Auto-play advances to the next slide when voiceover finishes

## Cost per lesson

Roughly **$0.005 – $0.02** per lesson (one Claude Sonnet 4.6 call, ~3k–8k tokens total).

Compare to the previous stack: ~$0.05 – $0.15 per lesson (DALL-E + GPT + TTS).

## Operator status

`GET /healthz` returns `{"ok": true}` for the host health check.

`GET /debug/status` is private. Sign in at `/admin`, or send the Render `ADMIN_SECRET` only as a header (never in the URL):

```bash
curl -sS -H "X-Admin-Secret: $ADMIN_SECRET" https://www.asklilowl.com/debug/status
```

The JSON field `git_commit` is the deployed commit. `POST /admin/clear-cache` uses the same header and deletes saved lessons.

When `SITE_PASSWORD` is set, that curl still works: `X-Admin-Secret` satisfies the site gate on `/debug/status` and `/admin/clear-cache` only. The private lesson API's bearer token does the same for `/api/admin/private-lessons` and its subpaths. A missing or wrong credential gets the site password's 401. Other admin pages still need the site password first. `/healthz` does not, so Render's health check keeps working.

## Site password

Set `SITE_PASSWORD` on the Render service to ask for one shared password before any page or API route. Leave it unset, or empty, and the site stays public — existing routes behave as they do today.

While it is set:

- Visitors enter the password at `/login`. A correct password is stored in the signed session cookie for 30 days. `/logout` clears that flag. This stays closed until `FLASK_SECRET_KEY` is set to a non-empty value: the password is not accepted and no session is stored while that key is missing.
- `/healthz` and `/favicon.ico` stay open. `/static/...` stays open so the login page can load its files. `/sitemap.xml` stays behind the password.
- `/robots.txt` answers `Disallow: /`, and responses include `X-Robots-Tag: noindex, nofollow`.
- `/admin` keeps its own login as a second step behind this gate. `X-Admin-Secret` opens only `/debug/status` and `/admin/clear-cache`. The private-import bearer opens only `/api/admin/private-lessons` and its subpaths.

Failed tries are limited to 10 per 15 minutes for each visitor. Limits are counted per gunicorn worker, so the effective limit is up to workers × 10, and a restart resets them. The address is stored only as a one-way hash.

## Deploying to Render

- Build command: `pip install -r requirements.txt`
- Start command: `gunicorn app:app --bind 0.0.0.0:$PORT --timeout 180`
- Environment variables: `ANTHROPIC_API_KEY`, `ANTHROPIC_MODEL` (optional), `FLASK_SECRET_KEY`, `SITE_PASSWORD` (optional)
