# One-lesson pipeline implementation plan

> Agentic workers: use test-first implementation and independent, non-overlapping scopes; preserve the dirty worktree. No commit, key setup, paid calls, generation, production mutation or deployment in this implementation turn.

Goal: implement the user's approved make_lesson --next workflow with one private review slot and one-lesson lookahead after explicit approval. Target under180seconds is a measured objective, not a promise.

Architecture (updated for the user's NO PAID APIs directive): durable local queue and immutable locked source; reviewed local recipes and existing assistant-created artwork only. Installed local Kokoro is used because current server code uses OpenAI TTS and requirements do not install Kokoro. Four local artwork imports run concurrently with one cached local narration job. Existing package/import validators provide the storage boundary. A new, disabled-until-configured scoped HTTPS API replaces browser upload; no schema migration or public activation. Python cannot directly invoke the existing built-in assistant image tool, so fully standalone image creation remains unavailable rather than silently adding a paid API.

Safety gates: no paid provider calls or new paid service; no key generation/configuration/transmission without per-action approval; no deployment until separately approved. Example config defaults upload permission to disabled and supplies no recipe/artwork. Human approval remains required; structural image checks cannot guarantee anatomy/semantic accuracy. Keep 2x2 cube's existing16-step draft on hold rather than truncate it to4. Never claim built-in tool usage/Render hosting is universally free; only local tools have no per-call service fee.
